# Attendance Monitoring WebApp with QR and E-Signature Integration

This project is a PHP-based web application designed to streamline attendance monitoring through QR code scanning and electronic signature integration.

## Features
- **QR Code Integration**: Efficiently scan and verify attendance.
- **E-Signature Support**: Capture electronic signatures for authentication.
- **User-Friendly Interface**: Simplified and intuitive user experience.

## Requirements
- PHP 7.4 or higher
- Web server (e.g., Apache or Nginx)
- Database (e.g., MySQL)

## Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/Jesseraxe/Attendance-Monitoring-WebApp-with-QR-and-E-Signature-Integration.git
   ```
2. Set up your database and update the configuration files.
3. Serve the project through a local or remote web server.
